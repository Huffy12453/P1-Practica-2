Tipos de tablas

El objetivo fundamental de las tablas en HTML será mostrar una serie de datos en forma ordenada, organizado en filas y columnas.

Para la creación de una tabla intervienen diferentes elementos:

Table
Es la marca de comienzo de la tabla. Este elemento requiere la marca de cierre.
Tr
Es la marca de comienzo de una fila. Esta marca debe estar dentro del elemento table.
Td
Es la marca de comienzo de una celda. Esta marca debe estar dentro del elemento tr.

Ejemplo

Ciudad de México 9.2 millones
Guadalajara 4.1 millones
Monterrey 3.9 millones

Tabla con encabezado

La característica de esta tabla es que se le agrega a las celdas el encabezado correspondiente, esto solo aplicaría a la primera fila de la tabla con la etiqueta th, las demás filas usarían la etiqueta td con normalidad.

Ciudad Cantidad de habitantes
Ciudad de México 9.2 millones
Guadalajara 4.1 millones
Monterrey 3.9 millones

Tabla con título

Para insertar un título a la tabla debemos incorporar el elemento caption inmediatamente después de abrir la etiqueta table.
